EMAIL SIGNATURE - Atikul Islam Rabbi
====================================

FILES
- signature-icons/              5 small PNG logos (Facebook, Instagram, YouTube,
                                LinkedIn, Upwork) used by the signature
- atikul-email-signature.html   The signature (use this one)
- email-signature-preview.html  Same signature shown inside a sample email

IMPORTANT: COPY THE RENDERED SIGNATURE, NOT THE SOURCE CODE
- RENDERED = what you see in the browser window (the formatted signature).
- SOURCE   = the HTML tags you see in a text editor / Notepad.
Gmail and Outlook signature boxes need the RENDERED version.
Pasting the source code will show raw tags like <table> as plain text.

STEP 0 - UPLOAD THE ICONS FIRST (one time)
Email clients cannot use local files or embedded images reliably, so the icons
must be online at a public HTTPS address. The signature expects:
  https://cyber-infinity.github.io/signature-icons/facebook.png  (and the others)
1. Open your cyber-infinity.github.io GitHub repository.
2. Upload the whole "signature-icons" folder to the root of the repository
   (replace the old icons if you uploaded an earlier version).
3. Wait 1-2 minutes, then open one icon URL in your browser to confirm it loads.
If you use a different folder or domain, edit the image addresses in the HTML.

STEP 1 - OPEN AND COPY
1. Double-click atikul-email-signature.html. It opens in your browser.
2. Click just before the "AR" box, hold the mouse, and drag to select
   everything to the end of the last link row. (Or press Ctrl+A.)
3. Press Ctrl+C (Cmd+C on Mac).

STEP 2A - GMAIL
1. Gmail > gear icon > "See all settings".
2. General tab > scroll to "Signature" > "Create new".
3. Name it, click in the editor box, press Ctrl+V.
4. Set it as default for "New emails" and "Replies/forwards" if wanted.
5. Scroll down and click "Save Changes".

STEP 2B - OUTLOOK (desktop, Windows)
1. File > Options > Mail > Signatures.
2. Click "New", name it, click in the edit box, press Ctrl+V.
3. Choose it as default for new messages and replies, then OK.

STEP 2B - OUTLOOK (new Outlook / web)
1. Settings (gear) > Accounts > Signatures
   (or Mail > Compose and reply).
2. Click "New signature", paste with Ctrl+V, Save.

STEP 3 - TEST
1. Send a test email to yourself and to a second address (e.g. Gmail + Outlook).
2. Open it on desktop AND on your phone.
3. Click every link: WhatsApp, atikulislam.me, email, Agency, Upwork,
   LinkedIn, Facebook, Instagram, YouTube.
4. Check that the layout is not broken and the text is readable.

NOTES / LIMITATIONS
- Email clients render HTML differently; small spacing differences are normal.
- Dark mode: some apps (Gmail, Outlook mobile) auto-invert colors. The "AR" box
  and blue links usually stay readable, but dark text may appear lighter.
- Some clients (Outlook desktop) may ignore the thin vertical divider line
  or show slightly different spacing. Layout stays intact.
- Icons are images. If a client blocks images, the platform name appears
  instead (alt text) and the links still work.
